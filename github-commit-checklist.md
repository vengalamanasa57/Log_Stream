# GitHub commit checklist

1. Upload the extracted files into the matching repository paths; do not upload the ZIP itself.
2. Confirm the new `alerting` and `config` Java files appear under `backend/src/main/java/com/logstream/`.
3. Confirm `docs/alerting-api.md` and `sample/alert-rule.json` appear.
4. Commit with message: `Add initial scheduled log alerting API`.
5. Build and run the backend locally before describing alerting as complete.

Do not upload `.git/`, `target/`, or `node_modules/`.
